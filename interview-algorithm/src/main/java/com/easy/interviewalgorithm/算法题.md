# 大厂高频算法与数据结构面试清单

>
> 适用：后端、AI 工程、全栈、SRE，国内互联网 / 外企大厂，笔试 + 手撕面试，区分**必掌握、高频、中等偏难、了解即可**。结合国内大厂（字节、阿里、腾讯、美团、百度）+ 外企（微软、Citadel 等）真实出题倾向。

## 一、必考基础数据结构（必须手写、懂底层）

表格

| 数据结构 | 重点考察点 | 经典题 |
| --- | --- | --- |
| 数组 | 双指针、滑动窗口、前缀和、差分 | 两数之和、三数之和、接雨水、最长连续子数组 |
| 链表（单 / 双链表） | 反转、环、快慢指针、合并、删除节点 | 反转链表、链表相加、环形链表、相交链表、k 个一组反转 |

## 二、树（面试超级高频，几乎必问）

1. **二叉树**

- 遍历：前 / 中 / 后序（递归 + 迭代）、层序 BFS
- 特性：对称树、平衡二叉树、树的深度、公共祖先
- 经典题：二叉树层序遍历、最近公共祖先、二叉树直径、路径总和

2. **二叉搜索树 BST**：中序有序、删除 / 插入、第 K 大元素
3. **堆（优先队列）** ⭐非常高频
    - 大顶堆、小顶堆，Java PriorityQueue / Python heapq
    - topK 问题、中位数、合并 k 个有序链表
4. **Trie 字典树**：字符串前缀搜索，高频出现在字节

>
> 树两大套路：DFS 深度优先、BFS 广度优先，大部分树题都可以套这两个框架。

## 三、图（中等难度，笔试常考，面试看岗位）

- 存储：邻接表（重点）、邻接矩阵
- 遍历：DFS、BFS
- 算法：
    - 并查集 Union‑Find：连通分量、岛屿数量（国内大厂超级爱考）
    - 最短路径：Dijkstra（重点），Floyd 了解
    - 拓扑排序：课程表问题

>
> 后端岗位图不会考特别难，**并查集是重中之重**。

## 四、高频算法思想（核心，比记题更重要）

### 1. 二分查找⭐⭐⭐⭐⭐（笔试手撕常客）

- 普通二分、左边界、右边界、旋转排序数组
- 题：搜索旋转数组、寻找重复数、二分答案（最大值最小化）

### 2. 双指针

- 快慢指针（链表）、左右指针（数组）

### 3. 滑动窗口

- 求最长 / 最短子数组、子串，字符串类大量题目使用

### 4. 回溯 DFS（子集、排列、组合）

子集、全排列、组合总和，八皇后，注意剪枝优化。

### 5. 动态规划 DP ⭐⭐⭐⭐

大厂必考，难度跨度大

- 入门：爬楼梯、打家劫舍、最大子数组和
- 中等：最长递增子序列 LIS、最长公共子序列 LCS、背包（01 背包、完全背包）
- 高频真题：股票买卖系列（多道）、编辑距离

>
> 国内后端一般不会出极难 DP；量化、外企 Citadel 类会加大 DP 难度。

### 6. 贪心

区间调度、跳跃游戏；注意：贪心要能证明正确性，面试容易追问为什么可以贪心。

## 六、不同岗位侧重点差异

1. **普通后端 Java/Python 开发**

>
> 重点：数组、链表、树、二分、双指针、滑动窗口、简单 DP、堆；图考并查集为主；hard DP 很少。

2. **AI 工程 / Agent 工程师**

>
> 算法难度中等，偏向基础，常考：链表、树、二分、topK、滑动窗口、简单 DP；会穿插系统设计，纯算法题量比后端少。

3. **量化开发（Citadel、九坤幻方）**

>
> DP、贪心、数学、模拟、Dijkstra、复杂二分答案，hard 题比例明显提升。

4. **外企微软**

>
> 注重代码规范性、边界 case，中等题为主，喜欢链表、树、设计题。

## 七、不常考，了解即可

- KMP 字符串匹配：大部分大厂只需要知道思想，很少手写完整 KMP
- 红黑树：**不用手写！掌握特性、增删特点、和 AVL 树对比**
- B + 树：数据库索引，口述原理，不用写代码
- 各种高级平衡树、线段树、树状数组：算法竞赛高频，普通开发岗极少，只有部分笔试会出现

## 八、面试刷题策略建议

1. 优先刷：`easy全部 + medium高频题`，hard 挑经典即可，不要死磕竞赛题
2. 每道题要思考：时间复杂度、空间复杂度、边界 case（空输入、单元素、重复元素）
3. 面试手撕重点：**递归转迭代、不使用额外空间版本、原地修改**，面试官最爱追问优化空间。
